Characters

Upload a picture of a character, name it, then write @name in a video or image prompt to keep that character's look (an image prompt with a character makes 1 image, edited from the reference). Plain backgrounds work best: the model copies whatever else is in the picture, so use Clean up to redraw it as a white-background character sheet (~$0.07, via Gemini; non-explicit designs only). Use original or cartoon characters, not photos of real people.
