    Use it from opencode (any laptop)

    The address never changes between launches, so you set this up once per machine.

    1. Install opencode: 
      curl -fsSL https://opencode.ai/install | bash
      or npm i -g opencode-ai / brew install sst/tap/opencode
    2. Save this as ~/.config/opencode/opencode.jsonc (%USERPROFILE%\.config\opencode\opencode.jsonc on Windows). If the file already exists, merge the "skdev" block into its "provider" section. 
      Loading…
    3. Launch a profile above and wait for serving (8–20 min).
    4. Test it: 
      opencode run "say hi in five words"
      Then use opencode normally. Pick private-llm-fast in /models when you launched the Fast profile, so auto-compaction triggers at its smaller window.

    The key in this snippet only works through llm-api.skdev.one and can be rotated on the server without touching the GPU box. If the box is off, opencode gets a clear "offline" error instead of hanging.
